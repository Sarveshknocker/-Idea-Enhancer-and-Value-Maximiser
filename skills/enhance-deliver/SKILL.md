# Deliver the Value Blueprint

1. Fill `references/blueprint-template.md` → `.enhancer/VALUE_BLUEPRINT.md`. Keep it scannable: tables, short paragraphs, every claim linked to a source or labelled assumption/estimate.
2. Optional (if asked, or if the idea is for fundraising/partners): `.enhancer/ONE_PAGER.md`: problem, solution, why now, market, business model, traction plan, ask.
3. Quality bar before handing over:
   - [ ] The transformed concept is explainable in one sentence
   - [ ] The v1 core passes the simplicity filter
   - [ ] ≥ 3 premium enhancements with evidence and a monetization path
   - [ ] Every number is sourced or labelled
   - [ ] Riskiest assumption has a concrete experiment runnable this week
   - [ ] Sources section lists every link used, with grades
4. Summarise to the user in ≤ 15 lines: one-sentence concept, top 3 enhancements, how it makes money (with price anchor), the first experiment, and the path to the full blueprint.
