## Idea Enhancer & Value Maximiser

This workspace has the **Idea Enhancer & Value Maximiser** kit at `{{KIT}}/`. Whenever the user shares an **idea or a problem** (any category) and wants it improved, solved, validated, monetized or made premium — or says "enhance this idea" — **follow the kit instead of improvising**:

| Task | Open and follow |
|---|---|
| Full autonomous enhancement (end to end) | `{{KIT}}/skills/idea-enhancer/SKILL.md` |
| OSINT research (GitHub, Reddit, X, HN, papers, patents, open data) | `{{KIT}}/skills/enhance-research/SKILL.md` |
| Cross-domain creative connections + simplicity filter | `{{KIT}}/skills/enhance-connect/SKILL.md` |
| Monetization, pricing, market sizing, moats, value scoring | `{{KIT}}/skills/enhance-value/SKILL.md` |
| Stress-test & validation experiments | `{{KIT}}/skills/enhance-validate/SKILL.md` |
| Value Blueprint / one-pager | `{{KIT}}/skills/enhance-deliver/SKILL.md` |

Sub-agent role briefs (if your tool supports sub-agents): `{{KIT}}/agents/`.
Scripts are dependency-free Node ≥ 18: run them with your terminal tool; use your web search tool for sources without free APIs (X/Twitter, patents, Product Hunt, pricing pages).

**Mode: autonomous.** One message with an idea → a finished `.enhancer/VALUE_BLUEPRINT.md`: frame → research → connect → maximise value → stress-test → deliver. Record assumptions instead of asking; ask only if the input has no identifiable problem.

Always: compute market size, unit economics and experiment sizes with `{{KIT}}/skills/enhance-value/scripts/economics.mjs`; cite real sources (never invent numbers or links), keep the core solution simple, make monetization honest, and research topics — not private individuals.
